# SARAI Jarvis 3.0 — Test Credentials

No authentication system — this app does not require login.
All features are accessible without credentials.

## API Endpoints
- Backend: https://35de459b-7ffd-486c-a674-1e2c5b6bba45.preview.emergentagent.com
- Health: GET /api/health
- Add thought: POST /api/thoughts
- Get graph: GET /api/graph
- Timeline: GET /api/timeline
- Stats: GET /api/stats
- TTS: POST /api/tts
- STT: POST /api/stt (multipart audio)
- Agent analysis: POST /api/agents/analyze
- Chat: POST /api/chat
- Delete thought: DELETE /api/thoughts/{id}
